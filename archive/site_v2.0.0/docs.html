Data dictionary

Products: adm2 native · adm1_wb World Bank ADM1 · adm1_gadm41 GADM 4.1 ADM1. Frequencies: m monthly · a official annual composite · afm annual derived from monthly.

Status: source copied from the source table · exact exact aggregation of source values · exact* exact where the weight is recoverable; flagged when estimated · derived computed here from other columns · crosswalk depends on the geographic crosswalk (approximate by nature)

File layout

data/v2/
  adm2/{monthly,annual}/<ISO3>.{parquet,csv}                 native districts
  adm1_wb/{monthly,annual,annual_from_monthly}/<ISO3>.{parquet,csv}
  adm1_gadm41/{monthly,annual,annual_from_monthly}/<ISO3>.{parquet,csv}
  <product>/<product>_<freq>_global.{parquet,csv.gz}       (large ones in the GitHub release)
  crosswalks/                                                 ADM2 → GADM 4.1, match quality, QA
  data_dictionary.{csv,json} · build_meta.json · manifest.json · validation.json

Keys: ADM2CD_c + time (ADM2), ADM1CD_c + time (World Bank ADM1), GID_1 + time (GADM). Time is date (YYYY-MM) plus year/month in monthly files, year otherwise. Missing values are empty cells in CSV and nulls in Parquet/Stata; a zero always means observed darkness.

Version history

  • v2.0.0 (2026-11-21) — Native ADM2 product; no-data sums set to missing instead of 0; flagged estimated pixel weights; official annual and monthly-derived annual kept separate; log/asinh transforms and year-on-year changes; GADM 4.1 match grades and absorbed-unit flags; DOSE V2.14 linkage and ready-to-merge panel; US BEA and Brazil IBGE crosswalks; Stata files; validation report incl. direct-extraction benchmark; new portal.
  • v1.1.0 (2026-11-20) — GADM 4.1 ADM1 version via an ADM2 crosswalk.
  • v1.0.0 (2026-11-20) — First release: World Bank ADM1 aggregation and explorer.

Releases are immutable: a new source revision produces a new version; earlier versions stay available from their GitHub release and git tag.
