Method

  1. Source. The World Bank's Space2Stats Monthly & Annual Black Marble Nighttime Lights (v2, CC BY 4.0) aggregates NASA Black Marble (VNP46A3/A4, 15 arc-second) radiance to 39,366 ADM2 units of the World Bank Official Boundaries.
  2. Nesting. Every ADM2 unit carries exactly one ADM1 code from the same boundary vintage, so the aggregation is a pure group-by. No spatial overlay is needed, and no ADM2 is split or double counted.
  3. Sums and maxima add up exactly. Country totals recomputed from the ADM1 file match the ADM2 source to floating-point precision (relative error < 10⁻¹⁵).
  4. Means are pixel-weighted. The source mean is taken over valid pixels, so each ADM2's valid-pixel count is recovered as sum ÷ mean. For completely dark units (sum = mean = 0), it is the unit's static pixel count × (1 − share missing). ADM1 mean = Σ sums ÷ Σ valid pixels. Every ADM1 mean lies within the range of its ADM2 means (checked for all 649,246 unit-periods).
  5. Quality. Clouds, and summer twilight at high latitudes, leave pixels without valid observations. coverage reports the valid share. Sums for low-coverage months are underestimates, so filter on coverage for time-series work.
  6. Annual ≠ mean of months. Annual values come from NASA's annual composite, not from averaging the monthly files. The 2025 annual composite was not yet in the source when this was built.

About the map

The source table uses an older vintage of the World Bank boundaries than the one published today, and some ADM1 codes were reused for different units in between. For example, ALB005 is Dibër in the data but Fier in today's boundaries. To avoid putting values on the wrong polygon, an outline is drawn only when code and name agree, or names match one-to-one in a country with an unchanged unit count. 2,641 of 3,587 units are mapped; 366 of these are flagged as approximate outlines because their country has gained or lost a few units. Every unit is in the downloads either way. The audit file lists the status of each one.
