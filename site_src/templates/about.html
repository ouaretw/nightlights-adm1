About

Night Lights ADM1 makes global and subnational nighttime-light statistics reliable, interpretable and usable for economic research: a documented panel for states, provinces and districts, the code that builds it, and a small set of exploratory analyses.

On this page: Purpose · What it adds · Contributors · Open data and licences · Project status · Future indicators

Purpose

Most regional economic statistics are published for first-level administrative units (states, provinces, regions). The World Bank's Space2Stats Black Marble tables are published for second-level districts. This project aggregates those districts to first-level units with rules that are exact where the source allows it, links them to the geographies used by economic datasets, and publishes the result with its quality indicators, so that a researcher can merge nighttime lights with regional GDP without rebuilding the pipeline.

What it adds to existing tools

The World Bank already provides ADM1 access: the space2stats-stata package collapses the same district tables to ADM1, and blackmarble-stata / blackmarbler extract Black Marble directly for any polygon. This project does not replace either. What it adds, and what has been checked:

Open data and licences

1 · Source observations

Public, not ours

NASA Black Marble radiance and the World Bank Space2Stats district tables (CC BY 4.0) are public. Anyone can obtain them; this project claims no exclusivity over them and keeps their attribution in every file.

2 · Derived data and code

Licensed, versioned, access by password

The aggregated panels, crosswalks and quality indicators are licensed CC BY 4.0 and the code MIT, with version numbers and SHA-256 checksums. Since v3.0 this site is password-protected; the licence applies to everyone given access. A DOI-backed archive (e.g. Zenodo) is planned; none has been minted yet.

3 · Analyses and manuscripts

Exploratory here, papers elsewhere

The analyses on this site are exploratory and public. Interpretations prepared for publication are not posted here until published; that does not restrict access to the data.

Future indicators not ingested

Other Earth-observation products could be aggregated to the same units. None is active: an indicator is added only after real ingestion, validation against an independent reference, and complete metadata. Bands (reflectance in a wavelength range), indices (formulas of bands, such as NDVI) and derived geophysical products (temperature, built-up surface, modelled population) mean different things and are not interchangeable.
